Sistema de Gestión Académica

Sistema integral de administración escolar para el Liceo José Santos Ossa

El sistema fue desarrollado bajo una arquitectura MVC (Modelo-Vista-Controlador), con una base de datos relacional MySQL de 15 tablas, vistas SQL para reportes complejos, triggers de validación y auditoría automatizada.

Información del Proyecto

Descripción y Contexto

Proyecto desarrollado para un ramo universitario. Consiste en un sistema web completo de gestión académica diseñado para el Liceo José Santos Ossa. El sistema permite administrar todo el ciclo escolar: desde la matrícula de estudiantes hasta el registro de notas, asistencia y generación de documentos oficiales.

Problema que Resuelve

El liceo carecía de un sistema digitalizado para la gestión de sus procesos académicos y administrativos. El registro manual de notas, asistencias y matrículas generaba errores, pérdida de información y dificultad para acceder al historial de los estudiantes. Este sistema centraliza toda la información en una plataforma web accesible y organizada.

Funcionalidades Principales

  • Gestión de Estudiantes: Registro completo con datos personales, foto de perfil e historial académico consultable por año.
  • Gestión de Apoderados y Parentescos: Vinculación familiar con roles (titular, suplente, financiero) y permisos de retiro.
  • Matrículas: Inscripción por año académico y curso con estados (Cursando, Aprobado, Reprobado, Retirado).
  • Registro de Notas: Calificaciones por período con indicadores visuales (verde/rojo) y escala 1.0 a 7.0.
  • Control de Asistencia: Registro por semestre con cálculo automático de porcentaje y alertas por nivel.
  • Solicitud de Documentos: Sistema de solicitudes con generación automática de código único (SOL-AAAA-NNNN).
  • Sistema de Roles: Tres niveles de acceso — Administrador, Administrativo y Apoderado — con permisos diferenciados.
  • Auditoría: Registro automático de eliminaciones con trazabilidad de responsable y motivo mediante triggers.
